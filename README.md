# **Image Editor From Scratch**

## **Overview**
Image editor from scratch using **Python, NumPy, and Tkinter**. The editor includes various image processing features such as brightness, contrast, saturation adjustments, sharpening, auto-enhancement, blur effects, seasonal filters, and artistic effects like crayon and pencil sketch.

## **Features**
| Feature               | Description |
|-----------------------|-------------|
| **Brightness**       | Adjusts the image brightness. |
| **Contrast**         | Modifies the contrast level of the image. |
| **Saturation**       | Enhances or reduces the color intensity. |
| **Sharpening**       | Increases the sharpness to highlight details. |
| **Auto Enhance**     | Automatically adjusts image quality. |
| **Blur**            | Applies a blur effect to the image. |
| **Summer Filter**    | Adds a warm, summer-like tone. |
| **Winter Filter**    | Applies a cool, winter-like effect. |
| **Crayon Effect**    | Converts the image to a crayon sketch. |
| **Pencil Sketch**    | Converts the image into a pencil sketch. |

## **Technologies Used**
- **Python** for scripting
- **NumPy** for image processing
- **Tkinter** for GUI development
